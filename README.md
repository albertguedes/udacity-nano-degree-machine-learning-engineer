# Udacity Machine Learning Engineer Nanodegree

Repository of projects completed for Udacity's **Machine Learning Engineer Nanodegree**.

## Projects

### Supervised Learning

| Project | Description |
|---------|-------------|
| [boston_housing](boston_housing/) | Predict house prices in Boston using regression algorithms |
| [finding_donors](finding_donors/) | Predict potential donors using classification algorithms |

### Unsupervised Learning

| Project | Description |
|---------|-------------|
| [customers_segments](customers_segments-pt_BR/) | Customer segmentation using clustering algorithms |
| [quadcopter](quadcopter/) | Train a virtual quadcopter to fly using reinforcement learning |

### Applied ML

| Project | Description |
|---------|-------------|
| [student_intervention](student_intervention-pt_BR/) | Predict student dropout risk using classification |

## Tech Stack

- Python
- scikit-learn
- Pandas / NumPy
- Jupyter Notebooks
